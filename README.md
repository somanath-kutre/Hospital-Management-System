# MediCare HMS – Hospital Management System (Django)

Appointments, patient records, OPD & IPD (admission / bed / discharge), treatments,
prescriptions and billing, with role-based access.

## Quick start
```bash
python -m  venv venv && source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
python manage.py makemigrations accounts patients appointments clinical billing
python manage.py migrate
python manage.py seed_demo          # optional demo users + sample data
python manage.py runserver
```
Open http://127.0.0.1:8000/  (Django admin: /admin/)

> Migrations are generated by the `makemigrations` step above (run it once, `accounts` first
> because it holds the custom User model).

## Workflow
1. Receptionist registers a patient (optionally creates a portal login) and books an appointment.
2. Doctor opens the appointment -> **Start consult** creates an OPD record. For admissions, front desk/doctor creates an **IPD** record and picks a free bed (bed becomes occupied).
3. Doctor records diagnosis, treatments (with optional charge) and prescriptions (printable).
4. **Discharge / Complete visit** closes the record and frees the bed.
5. Front desk clicks **Generate invoice** (consultation fee + bed days x daily charge + billable treatments), adds items/discount, records payments (cash/card/UPI/insurance). Status: Unpaid / Partial / Paid.

Set up wards, beds (with daily charge) and doctor fees in the Django admin or via **Staff → Add staff** (doctor fee).

## Tests
`python manage.py test` – covers role access, double-booking, IPD bed lifecycle and billing.
